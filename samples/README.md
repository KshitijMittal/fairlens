# Bundled samples (F11)

The three datasets the landing page runs in one click, also used verbatim as
backend test fixtures. Each CSV starts with `#` comment lines (source,
licence, exact perturbation) that the parser skips.

| File | Group column | Outcome | Documented historical parity ratio | Documented verdict |
|---|---|---|---|---|
| `loan_approvals.csv` | `gender` | `decision` = `approved` | **0.695** (fail band) | Fail — C1 and C2 fail |
| `hiring_shortlist.csv` | `ethnicity` | `shortlisted` = `yes` | **0.875** (warn band) | Warn — C1 and C2 warn |
| `scholarship.csv` | `region` | `awarded` = `yes` | **0.995** (pass band) | Pass — all five checks green, no Inconclusive |

## Sources and licences

- **loan_approvals.csv** — derived from real data. UCI Machine Learning
  Repository, [Statlog (German Credit) Data Set](https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data),
  Hans Hofmann, 1994. Licence: **CC BY 4.0**. The source has no identifier
  columns. The 1,000 source rows are subsampled to 908: every female denial plus
  110 of the 201 female approvals (219 women), and every male denial plus 498 of
  the 499 male approvals (689 men), which gives the 0.695 ratio. Then 6 exact
  duplicate rows are added (914 rows), 12 `housing` and 8 `employment_years`
  cells are blanked, and letter casing is mixed in `gender` and `purpose`. The
  exact recipe is `scripts/make_samples.py`.
- **hiring_shortlist.csv** — synthetic, CC0. Generated by
  `scripts/make_samples.py` (seed 20261102): interview score tracks skill;
  `prestigious_school` correlates with ethnicity (45% vs 15%) so a proxy
  exists; shortlisting adds a fixed `group_b` offset producing the warn-band
  ratio.
- **scholarship.csv** — synthetic, CC0. Generated by `scripts/make_samples.py`
  (seed 20261103): awards depend on GPA, entrance score and extracurriculars
  only; `region` and `age_band` are independent of the outcome, so both
  outcomes appear in every group and all five checks can pass.

Regenerate with `python scripts/make_samples.py` from the repository root.
